# 🔒 WA Privacy Extension

A simple Chrome extension that helps protect your privacy on WhatsApp Web by blurring sensitive information.

## ✨ Current Features

- 🖼️ Blur Profile Pictures
- 👤 Blur Contact Names
- 📞 Blur Contact Details / Phone Numbers
- 💬 Blur Chat Message Content

## 📥 Installation

1. Download or clone this repository.

```bash
git clone https://github.com/your-username/wa-privacy-extension.git
```

2. Open Chrome and navigate to:

```
chrome://extensions
```

3. Enable **Developer Mode**.
4. Click **Load Unpacked**.
5. Select the extension folder.

## 🚀 Usage

1. Open WhatsApp Web.
2. Click the WA Privacy Extension icon.
3. Enable the blur options you want.
4. Sensitive information will be blurred automatically.
